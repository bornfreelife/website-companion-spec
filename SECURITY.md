# Security policy

## Supported versions

This is a pre-1.0 draft. No version is currently approved for production use.

## Reporting a vulnerability

Use GitHub's private vulnerability-reporting feature for this repository. Do not open a public issue for an unpatched vulnerability and do not include user data, private keys, tokens, or production credentials in a report.

Include the affected document/schema, attack preconditions, impact, and a minimal reproduction using synthetic data. Maintainers will acknowledge a report, coordinate a fix and disclosure, and add a regression fixture where appropriate.
